**크롭 개수 가이드(F-CRP-03)는 `should`(12월)입니다.** MVP에는 권장 개수 안내가 없습니다.
단, 예외 조항의 "크롭 0개 진행 차단"은 S2 화면정의서에도 명시되어 있으므로 MVP에 포함합니다.

### Spike①에서 추가로 정의한 방어 (문서에 없던 항목)

기획 문서에 없어 **임의의 비즈니스 규칙을 만들지 않고** 상수로 분리했습니다.

| 조건 | 처리 | 상수 |
|---|---|---|
| previewScale 0·음수·NaN·누락 | 표시 중단 + 사유 안내 | — (0 나눗셈 방지) |
| zoomScale 범위 밖 | 0.1~4배로 clamp | `ZOOM_MIN` `ZOOM_MAX` |
| 원본 width/height 미수신 | 크롭 차단 | — |
| 이미지 로딩 전 크롭 시도 | 차단 + 안내 | — |
| 클릭 수준의 미세 드래그 | 크롭 생성 안 함 | `MIN_CROP_SOURCE_PX` (오조작 방지용) |
| 모듈 규격 미만 크기 | 경고 | `CROP_WARN_MIN_WIDTH/HEIGHT` (= 970×300 잠정) |

`CROP_WARN_MIN_*`의 실제 수치는 **미확정**입니다.
F-CH-05a의 "짧은 변 500px"은 `scope=thumbnail`이라 A+ detail(970×300)에 적용되지 않습니다(v2.2 정정).
따라서 500을 쓰지 않고 모듈 규격 자체를 잠정 기준으로 두었습니다.
